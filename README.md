# Simulador_RLC
Simulador interativo de circuitos RLC (Série, Paralelo e Misto) desenvolvido em Python e Streamlit. Permite gerenciar componentes, calcular a impedância equivalente, corrente, potências e fator de potência, além de gerar o esquemático do circuito, o diagrama fasorial e o triângulo de potências em tempo real.
